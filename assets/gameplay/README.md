# Gameplay Footage Directory

Place your background gameplay clips (.mp4, .mov, .mkv) in these folders:
- `assets/gameplay/gta5/`: GTA 5 car stunt / mega ramp clips
- `assets/gameplay/minecraft/`: Minecraft parkour clips
- `assets/gameplay/subway_surfers/`: Subway Surfers endless run clips

The bot automatically rotates between these in every generated video,
crops to 1080x960, and picks a random starting offset for variety.
